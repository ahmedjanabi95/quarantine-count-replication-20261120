# Local sub-400-ms follow-up
Triggered when the initial calibration on the workstation had no qualifying candidate. Initial calibration and fallback results remain in the primary study. This design was fixed after seeing the initial calibration and before acquisition of any of these follow-up trials. It tests intermediate delays instead of treating the 400-ms fallback as a test of a shorter local timer.
Boot an independent writable overlay of the same workstation guest installation after the original acquisition shuts down. Perform calibration and held-out evaluation within the same running guest. Cross delays 325, 350 and 375 ms with three new calibration seeds and four settings (36 trials). Choose the shortest delay with 12/12 eligible correct releases. If none qualifies, choose the shortest delay tied for the most correct releases and explicitly mark it unqualified. Freeze the selected timer before six further fresh clean seed blocks (48 trials) and one masked block (8 trials). Held-out schedules, pairing, meter eligibility and endpoints follow the primary study. All results are disclosed irrespective of qualification. Reboot and schedule changes prevent a paired comparison with the original local grid.
